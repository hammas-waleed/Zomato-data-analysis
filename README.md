ZOMATO RESTAURANT DATA CLEANER + EDA

A beginner-friendly Python project for cleaning and exploring the Zomato restaurant dataset using Pandas, NumPy, and Matplotlib.

TECHNOLOGIES USED

Python
Pandas
NumPy
Matplotlib
YData Profiling

PROJECT OVERVIEW

This project covers the basic Data Cleaning and Exploratory Data Analysis (EDA) workflow.

Main tasks performed:

* Loaded and explored the Zomato dataset
* Checked data types and dataset information
* Cleaned Rating and Cost columns
* Filtered and sorted restaurant data
* Performed basic statistical analysis
* Created new features using Pandas and NumPy
* Handled missing values using Mean, Median, Mode, and Forward Fill
* Removed duplicate records
* Used value_counts() and groupby() for analysis
* Created Cost vs Rating scatter plot
* Created Top 10 Cuisines bar chart
* Generated a YData Profiling report
* Detected Cost outliers using the IQR method
* Saved the cleaned dataset

OUTPUT FILES

zomato_cleaned.csv — Cleaned dataset

report.html — Dataset profiling report

HOW TO RUN

Install the required libraries:

pip install pandas numpy matplotlib ydata-profiling

Make sure zomato.csv is in the same folder as the Python file.

Run the project:

python zomato_data_project.py
